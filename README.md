# Лабораторні роботи

Портал лабораторних робіт студента групи **ІПЗМПм-11 Боднаря Андрія** (№1 у списку групи).

| Дисципліна | Роботи |
|---|---|
| Методи аналізу інтервальних даних (МАІД) | ЛР1 — обчислення інтервальних виразів і комплексних інтервалів; ЛР2 — інтервальні матриці, Q = B × C − A; ЛР3–ЛР6 — у розробці |
| Теорія надійності програмних систем (ТНПС) | ЛР1–ЛР5 — у розробці |

Стек: React 19, TypeScript, Vite, React-Bootstrap (Bootstrap 5.3), Vitest.

## Запуск

Потрібен Node.js 20.19+ (рекомендовано 24).

```bash
npm install
npm run dev        # http://localhost:5173
```

| Команда | Що робить |
|---|---|
| `npm run dev` | dev-сервер з гарячим перезавантаженням |
| `npm test` | тести (обчислення, реєстр дисциплін, межі ядра) |
| `npm run lint` | перевірка коду (oxlint) |
| `npm run build` | перевірка типів і збірка в `dist/` |
| `npm run preview` | перегляд зібраної версії |
| `npm run report -- …` | звіти у Word/PDF (див. «Звіти») |

## Структура

```
src/
  profile.ts            дані студента (ПІБ, група, номер у списку = варіант)
  shell/                оболонка: меню, блок студента, головна, сторінки дисципліни й роботи
  shared/               спільне: «вікна», вибір варіанту, сховище, тема, маршрути
  subjects/
    registry.ts         перелік дисциплін
    types.ts            опис дисципліни та роботи
    maid/               Методи аналізу інтервальних даних
      meta.ts           назва, роботи, сторінки
      core/             обчислення без React
      components/       матриці, комплексна площина, покрокова таблиця
      pages/            ЛР1, ЛР2, довідка
    tnps/               Теорія надійності програмних систем
tools/report/           генератор звітів (у збірку сайту не входить)
public/reports/         PDF-звіти для кнопки «Звіт»
tests/
  subjects/<дисципліна>/   тести обчислень
  shared/                  тести реєстру та архітектури
```

**Нова дисципліна** — тека `src/subjects/<id>/` з `meta.ts` і рядок у `registry.ts`.
**Нова робота** — сторінка в `pages/` і запис у `works` у `meta.ts`.

Адреси сторінок: `#/` — головна, `#/maid` — дисципліна, `#/maid/lab1` — робота.

## Звіти

Генератор у `tools/report/` збирає звіти з того самого ядра, що й сайт, і сам робить скриншоти «вікон»
(headless Chromium, 1366×768, світла тема). PDF робиться через LibreOffice (`soffice`).

```bash
npx playwright-core install chromium-headless-shell   # один раз
npm run report -- maid/lab2            # report/Боднар_МАІД_ЛР2.docx
npm run report -- all --pdf            # усі звіти, Word + PDF
npm run report -- all --publish        # + копія PDF у public/reports/ для кнопки «Звіт»
```

`report/` у git не потрапляє — це робочі файли для правок і здачі. Посилання для кнопки «Звіт»
задаються в `src/reports.ts` (`'maid/lab1': 'reports/maid-lab1.pdf'`); тест перевіряє, що файл існує.
**Новий звіт** — модуль у `tools/report/labs/` і рядок у `REPORTS` у `tools/report/build.ts`.

## Примітки щодо обчислень (МАІД)

- Множення й ділення інтервалів: min/max чотирьох добутків (часток) кінців.
- Ділення на інтервал, що **містить 0 усередині**, виконується тим самим правилом, як у лекції 1 (приклад 3),
  і позначається попередженням; якщо межа дільника дорівнює 0 — це помилка.
- Межі в інтерфейсі округлюються **назовні** до 4 знаків.
- Персональні дані для ЛР2 вводяться у формі й зберігаються лише в `localStorage` браузера.

## Публікація на GitHub Pages

1. Створити репозиторій і надіслати код у гілку `main`.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` запускає lint, тести, збірку та публікує сайт.
